# ㄅㄆㄇ 注音符號練習

一個給小朋友練習注音符號的網頁小遊戲，搭配可愛的寶可夢圖卡，點一下就能猜猜看、聽發音。純前端網頁，不需要安裝、不需要登入，手機、平板、電腦都能玩。

## 🔗 線上遊玩

👉 **https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPO_NAME/**

把連結分享給朋友，他們用瀏覽器打開就能直接玩了。

## ✨ 功能

- **總覽**：37 張注音符號卡片總覽，已學會 / 待複習會用顏色和圖示標示
- **練習**：
  - 可切換「依照順序」或「隨機練習」
  - 卡片上的寶可夢圖案會先被蓋住，點一下才會出現
  - 每張卡可以標記「😀 我會了」或「🤔 不熟，加入複習」
- **複習**：只出現被標記為「不熟」的卡片，複習完會自動從清單移除
- **統計**（給家長看）：
  - 已學會 / 待複習 / 尚未練習 / 累計練習次數 / 今天練習次數
  - 每次練習的紀錄表：時間、模式、題數、已學會、不熟、答覆率
- **發音**：點卡片上的注音符號或總覽縮圖旁的 🔊，會用系統內建語音念出該注音符號
- **響應式版面**：自動依手機 / 平板 / 電腦調整版面大小

所有練習進度、複習清單、統計紀錄都存在瀏覽器的 localStorage，只留在使用者自己的裝置上，不會上傳到任何伺服器。

不想用線上版的話，也可以下載後直接打開：

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/YOUR_REPO_NAME.git
```
